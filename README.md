# Flumenis Website

A bilingual, parallax-driven marketing site for Flumenis — an independent software company turning real-world signals into immediate, trustworthy insight.

## Getting started

```bash
npm install
npm run dev
```

Visit `http://localhost:5173` to view the site locally.

## Available scripts

- `npm run dev` – start the Vite development server
- `npm run build` – type-check the codebase and output a production build
- `npm run preview` – preview the production build locally

## Tech stack

- [React 18](https://react.dev/) with TypeScript and [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/) for utility-first styling
- [Framer Motion](https://www.framer.com/motion/) for cinematic scroll and parallax animations
- `@fontsource-variable/inter` for high-performance variable typography
